# Warehouse Management System - Frontend

This is the directory for the frontend application. 

You can bootstrap this project using:
- **React / Vite**: Recommended for a modern, fast Single Page Application (SPA).
- **Thymeleaf**: If integrating directly into the Spring Boot backend.

To start with React + Vite, run:
```bash
npx -y create-vite@latest ./ --template react
npm install
npm run dev
```
